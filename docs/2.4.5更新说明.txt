有压管网瞬态水力仿真平台 2.4.5
发布日期：2026-10-27

一、新增功能：科研接口
1. 无界面研究 API（hydraulic_moc.api，API 1.0）：以平台规划 JSON 为唯一输入，在界面之外直接调用平台的水力计算能力，结果附带平台版本、输入文件 SHA-256 和模型摘要，便于论文复现与结果归档。
   - 稳态评估：树状与环状管网，单组或成批评估轮灌组；H-W、D-W 与固定 Darcy 系数可逐管混用；环状管网采用全局梯度法求解。
   - 故障隔离：节点、管段、出水口三类故障按连通性自动隔离，环状管网自动改道供水。
   - 时间轴仿真：时变水源水头、故障与恢复事件，可挂接任意外部重规划器（如 NSGA-II），输出供水量、达标率、压力均匀度等指标。
   - 蒙特卡洛：固定种子、逐场景可复现，多进程并行，结果与进程数无关。
   - 精确缓存：按开启出水口与关闭管段组合缓存，重复评估不引入任何近似，大规模组合搜索显著提速。
2. 命令行：hydraulic-moc api describe | evaluate | simulate | monte-carlo，输入输出为 JSON、JSONL、CSV，每次运行生成 manifest 记录全部生效参数。
3. 轮灌组稳态评估器（irrigation_eval，命令 hydraulic-moc irrigation-eval）：面向轮灌调度研究的轻量评估接口，与无界面 API 在同一口径下逐位一致。
4. 研究口径默认值：EPANET 2.2 摩阻律、局部损失取 0.1 倍沿程损失、最低压力水头与设计压力 11.4 m、流速 0.3–2.5 m/s 只校核有流量管段。开箱即用，也可在 JSON 或命令行中逐项覆盖。

二、文档与示例
1. 新增《无界面研究 API》说明：输入格式、单位约定、模型选项、Python 与命令行用法、稳定性约定。
2. 新增最小示例：示例管网、轮灌组、时间轴场景与蒙特卡洛配置，一条命令即可运行。

三、兼容说明
1. 规划 JSON 中科研接口专用的选项放在 settings.hydraulic_api 下，桌面端界面不受影响，原有工程可直接使用。
2. 界面功能、工程文件格式与 2.4.4 相同。
