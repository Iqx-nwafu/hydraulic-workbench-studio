有压管网瞬态水力仿真平台 2.2.0 — 安装版使用说明

一、安装与启动
双击 HydraulicWorkbenchStudio-2.2.0-Windows-x64-Setup.exe，按向导完成安装。
程序仅为当前 Windows 用户安装，不需要管理员密码，无需另外安装 Python、CUDA。
安装完成后，可通过桌面或开始菜单中的“有压管网瞬态水力仿真平台”启动。
默认位置：%LOCALAPPDATA%\Programs\HydraulicWorkbenchStudio\client
Windows 10/11 64 位系统；请为安装和后续更新预留至少 2 GB 空间。

二、注册与登录
首次启动时选择“注册”，设置账户名和 6～20 位密码并提交申请。
请联系软件制作方审批账户并设置使用期限。获批后，在审批服务在线时首次登录。
成功在线登录后，可在授权有效期内使用离线登录。安装程序不附带审批中心。
安装版与 ZIP 版使用相同账户、授权流程和计算功能；安装不等于账户已经获批。
详细操作见程序 client 目录内的 ClientReadme.txt，以及 GitHub 仓库首页：
https://github.com/Iqx-nwafu/hydraulic-workbench-studio

三、软件更新
登录后打开右上角“设置 → 软件更新”，检查并安装制作方发布的新版本。
安装版保留原客户端更新器和签名配置，更新后仍可使用原桌面快捷方式。
更新时请先保存工况和结果，关闭正在运行的计算任务，不要强制关机。
正常更新保留 client\outputs 和用户授权；其他自建文件请保存到程序目录之外。
软件实际版本以软件界面显示为准；Windows 应用列表可能仍显示首次安装包版本。
若目录中已有更高版本，本安装包会停止安装，避免覆盖已经更新的客户端。

四、文件与卸载
不要单独移动 client 中的 EXE、模型、运行库或 auth_distribution.json。
不要删除安装目录内的 .installer 文件夹，它用于 Windows 正常卸载。
在 Windows“设置 → 应用”中找到本平台，选择“卸载”，或使用开始菜单的卸载入口。
卸载保留计算输出及当前 Windows 用户的账户授权、设置等本地数据。
用户自行添加的文件和后续更新新增的文件可能保留在原安装目录，请确认备份后自行整理。
卸载不会注销服务器上的账户。

五、给接收人的文件
发送一个 Setup.exe 即可安装；也可一并提供对应 .sha256 校验文件。
安装版与免安装 ZIP 版是两种取得同一客户端的方式，可按使用习惯选择。
