有压管网瞬态水力仿真平台 2.4.7 — 安装版使用说明

一、安装与启动

运行 HydraulicWorkbenchStudio-2.4.7-Windows-x64-Setup.exe，按向导完成安装。
程序仅为当前 Windows 用户安装，不需要管理员密码；运行于 Windows 10/11（64 位）。
请为安装和后续更新预留至少 2 GB 空间。程序携带运行依赖及本机 CPU 图纸识别组件，
无需另装 Python、PyTorch 或 CUDA，也不要求 NVIDIA 显卡。
安装后可从桌面或开始菜单的“有压管网瞬态水力仿真平台”启动。

安装版和完整免安装 ZIP 是取得同一客户端的两种方式，使用相同账户及计算功能。
免安装版必须完整解压，再运行 HydraulicWorkbenchStudioSecure.exe。

二、注册与登录

首次启动点击“没有账户？提交注册申请”，设置账户名、密码及确认密码，
填写手机号或邮箱（至少一项，建议填邮箱，忘记密码时可用它自助找回），
阅读《用户须知与隐私说明》并同意后提交。账户名为 3～32 个字符，密码为 6～20 个字符；
具体输入规则以界面提示为准。申请获批后，联网输入账户名及密码，点击“安全登录”。
忘记密码时点击登录页“忘记密码？找回密码”，用注册时绑定的邮箱接收验证码后设置新密码。
安装不等于账户已获批准。已有账户继续使用，无需因安装新版重新注册。

成功在线登录后，软件保存当前 Windows 用户的本机离线授权。后续服务连接失败时，
程序尝试使用有效的本机授权；仍点击“安全登录”，无需寻找独立离线按钮。
换电脑、换 Windows 用户或删除授权缓存后需重新在线登录。
详细操作见随包 ClientReadme.txt，以及仓库首页：
https://github.com/Iqx-nwafu/hydraulic-workbench-studio

三、更新与已有安装

更新前保存工况并备份工程及结果，等待运行中的计算或导出结束。
登录后点击右上角头像，选择“软件更新…”，检查并安装该窗口实际提供的版本
（2.4.5 及更早版本位于头像菜单“设置 → 软件更新…”）。
GitHub Release 与软件内更新服务分别发布；2.4.7 同时在 GitHub Release 和软件内更新提供，
已安装 2.4.5 或 2.4.6 的用户在软件内检查并安装即可，也可运行本版安装程序覆盖安装。
2.4.7 起软件内更新只下载有变化的文件，逐个校验 SHA-256 后与未变的文件组装成新版本；
从 2.4.6 及更早版本升级到 2.4.7 时下载完整更新包。
升级到 2.4.7 后首次登录需重新阅读并勾选更新后的《用户须知与隐私说明》。
更新期间不要强制结束更新器或关机，正常软件内更新后仍可使用原桌面快捷方式。

正常软件内更新保留程序内 outputs、auth_distribution.json 和当前 Windows 用户的授权、设置；
其他自建文件请保存到独立项目目录并自行备份，不要依赖更新器保留任意文件。
软件实际版本以程序界面为准，Windows 应用列表可能仍显示首次安装包的版本。
安装程序发现目标目录已安装更高版本时会停止安装，避免旧包覆盖新版；
无法读取现有版本时也会停止覆盖，请保留原程序并联系制作方。

手动升级可运行本版安装程序；也可将完整 ZIP 解压到新文件夹后运行。
不要将少量新版文件混合覆盖到旧程序目录。确认工况和结果可用后，再整理旧程序。

四、文件与卸载

保留整个客户端目录，不要单独移动 EXE、模型、运行库或 auth_distribution.json。
不要删除安装目录内的 .installer 文件夹，它用于正常卸载。
可在 Windows“设置 → 应用”中找到本平台并选择卸载，或使用开始菜单的卸载入口。
卸载保留计算输出及当前 Windows 用户的账户授权、设置等本地数据，不注销软件账户。
自行添加的文件和后续更新新增文件可能保留在原程序目录，请确认备份后自行整理。

五、下载与校验

Release：https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases
安装文件：HydraulicWorkbenchStudio-2.4.7-Windows-x64-Setup.exe
免安装文件：HydraulicWorkbenchStudio-2.4.7-Windows-x64.zip
请用本版 SHA256SUMS.txt 核对下载文件；来源不明或校验不一致时不要运行。

程序未提供 Windows Authenticode 代码签名，系统可能显示“未知发布者”。
文件 SHA-256 和更新元数据签名不是 Windows 代码签名，不要关闭安全防护来强行安装。
本仓库不公开软件源代码。GitHub 自动生成的 Source code (zip/tar.gz) 及 Code → Download ZIP
只包含公开仓库文件，不是软件源码或可运行客户端。
