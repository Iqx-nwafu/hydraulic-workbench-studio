有压管网瞬态水力仿真平台 v2.2.0——客户端使用说明

2.2.0 保留单管和管网 MOC/FVM，新增真实纵断面、沿线压力包络与冻结限值校核，
支持管网关阀方案的超限区段比较、归档重开和事务导出。取得本说明或本地生成安装文件不代表线上已发布，
实际更新须由软件制作方正式发布后提供。

1. 本客户端为 Windows 64 位免安装版本。请先完整解压压缩包，再双击
   HydraulicWorkbenchStudioSecure.exe。不要直接在压缩包预览窗口中运行。

2. 首次使用时请选择“注册”，设置账户名和 6～20 位密码。注册申请提交后，需由软件
   制作方在审批中心批准并设置使用天数；审批服务在线且账户获批后方可登录。

3. 已获批账户成功在线登录后，可在授权有效期内使用离线登录。注册、首次登录、
   密码更改、账户名变更、反馈发送和授权续期仍需审批服务在线。

4. 登录界面可选择“记住用户名”或“记住密码”。记忆信息由 Windows DPAPI 加密，
   只绑定当前 Windows 用户；共用电脑不建议启用“记住密码”。

5. 登录后可在右上角“设置 → 软件更新”检查新版本。更新元数据须通过 Ed25519
   签名和版本序列检查，完整更新包按签名元数据校验大小及 SHA-256。安装或
   启动检查失败时，更新器按既有机制尝试回滚。更新过程中请勿强制关机。

6. 登录后可在右上角“设置 → 界面语言”选择“中文（简体）”或“English”。
   切换时保留当前草稿和已有结果，不会要求重复登录。语言选择保存在当前 Windows
   用户的本地应用数据中；运行中的计算或导出任务结束后才能切换。

7. 请保留整个程序文件夹，不要单独移动主程序，也不要删除
   auth_distribution.json、HydraulicWorkbenchUpdater.exe 或程序运行库文件。
   正常更新保留 outputs 文件夹和 auth_distribution.json，不删除当前 Windows
   用户的本地账户授权及设置。更新前仍请备份 outputs 和自行保存的工况；其他
   自定义文件建议放在程序目录之外，不要依赖更新器保留任意文件。

8. 若审批中心暂时关闭，更新检查会提示连接失败，但不会影响已获得有效离线授权
   的账户继续使用软件。

9. 文件完整性可通过随压缩包提供的 SHA256SUMS.txt 校验。若文件来源不明、摘要
   不一致或 Windows 提示文件已被篡改，请停止运行并联系软件制作方。

10. v2.2.0 保留内置本机 CPU 图纸识别，支持 PNG、JPG、JPEG 和 DXF。
    无需另装 Python、PyTorch 或 CUDA，无需上传图纸；请保留 recognition_runtime
    文件夹及其中的模型。可从“文件”菜单或“管网计算 → 拓扑参数”的图纸导入区
    开始，查看后台环境检查状态及识别任务的文件名、阶段和耗时，并可取消任务。
    每次启动识别进程需要解包及模型加载，JPG/JPEG 通常比 PNG 慢，请等待状态
    提示。有效离线授权范围内可离线识图，账户登录和授权规则不变。

11. 识图后先预览并人工复核节点、管段、交叉线连接、水源和比例尺，再确认导入
    并补全真实水力参数。候选拓扑及默认参数不代表经过工程校核的实际管网。

12. 在“管网计算 → 瞬态计算设置”中可以显式选择 MOC 或 FVM。FVM 的“网格参考
    时间”用于划分每根管段的有限体积控制体，实际推进时间步由全网最小 dx/a 与
    Courant 数共同决定；结果输出间隔可以小于网格参考时间。运行按钮、检查中心、
    状态和结果摘要会显示实际方法，程序不会自动把不兼容的 FVM 工况改用 MOC。

13. 管网 FVM 支持普通分支/环网、异径异波速、定水头水源、需水变化、已有机械
    阀门、固定和准稳态摩阻。带经验局部损失的显式 NetworkTee、CLOSED 管段、
    管段局部损失系数和 Vitkovsky 非恒定摩阻暂不支持；检查中心会阻止计算。
    显式三通/局损/Vitkovsky 可选择 MOC；CLOSED 管段在两种方法中都须改用显式
    机械阀门表达关闭过程，或从活动拓扑移除。普通三分支连接节点不等于显式
    NetworkTee，仍可使用 FVM。两种方法均不包含空化或液柱分离，越过汽化阈值
    后的结果无效。

14. 正常运行的 1.1.9 客户端可在制作方正式发布 2.2.0 后使用内置更新。原 1.1.5
    更新器存在启动缺失模块问题；1.1.5 及更早受影响客户端请先使用配套的
    HydraulicWorkbenchUpdateRepair-1.1.8.exe 一次性修复工具，或完整解压新版
    客户端。仅在故障旧客户端中下载新包不能修复尚未启动的旧更新器。修复工具
    须等待制作方正式发布 1.1.8 或更高版本后使用，仍执行签名与完整性检查，
    不绕过账户登录和授权。请先备份数据，不要删除原账户本地应用数据。

15. 本程序未提供 Windows Authenticode 代码签名，系统可能提示“未知发布者”。
    更新元数据签名和文件 SHA-256 不等同于操作系统代码签名；只使用制作方提供
    且摘要一致的文件。无法核实来源时请停止运行，不要关闭安全防护来强行安装。

16. 工况参数更改后，已有结果仍对应运行时的输入，会标记为需要重新计算。
    加载其他工况、退出、注销或安装更新前，按提示保存、放弃或取消。检查中心
    与管网运行使用当前表单，包括尚未保存的修改。保存失败时应返回编辑处理。

17. 单管 MOC 对可能完全漏采的短脉冲会阻止计算，并给出网格细化建议。修改
    输出间隔不能修复 C=1 推进时漏采的问题。单管结果同时列出名义 CFL 步长、
    最大实际步长和请求输出间隔；FVM 中密集输出可能增加实际积分步数。

18. 导出在后台进行，可在提交前取消；再次导出只清理本软件同类交付的旧可选
    文件。若目标文件被其他程序占用，关闭占用程序后重试。模拟结果与校准
    记录可使用同一目录；共享文件名的不同模拟类型应分别导出。

19. “参数校准”中可取消正在计算的候选；失败或取消不会替换上一次完整结果。
    “导出完整校准记录”保存所有候选、输入工况、最佳工况和观测快照等证据。
    “应用最佳参数”会先确认波速、摩阻系数和固定 Darcy 模型的变更，再写入
    当前工况；随后重新计算并保存。原始校准记录保留供复核；拟合数据不能
    兼作独立验证，分段管道不使用两个全局参数进行校准。
