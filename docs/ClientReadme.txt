有压管网瞬态水力仿真平台 2.4.6 — 客户端使用说明

本平台用于单管及分支、环状管网的一维瞬态水力分析，支持 MOC/FVM、图纸识别与拓扑复核、
真实纵断面与压力校核、关阀方案比较、轮灌规划与监测布设及结果报告。
2.4.2 在 2.2.0 的计算能力基础上新增监测布设与轮灌、管径与轮灌联合设计、全局最优求解、
拓扑导出和文字标注，完善高清动态登录、本机头像、截图反馈、联系方式绑定、系统概况及按钮交互。
2.4.3 修复含中文路径时工况无法保存的问题，新增拓扑界面 Delete 删除、Ctrl+Z 撤销与
反馈回复查看。2.4.4 新增 AI 小助手、可拖动的节点/管段编号、文字与编号批量样式修改，
以及导出时可选是否带编号。2.4.5 新增无界面研究 API、科研命令行工具与轮灌组评估器。
2.4.6 采用全新 Qt 界面：项目浏览器四个工作域、菜单与快捷键直达常用操作、系统概况实时
显示检查与结果状态、联动的管网结果浏览器；网络计算与监测布设打通，新增邮箱找回密码、
反馈粘贴截图和科研命令行账户登录，AI 小助手可结合当前页面、检查结果和最近报错回答。
详细功能见“2.4.6更新说明.txt”“2.4.5更新说明.txt”“2.4.4更新说明.txt”
“2.4.3更新说明.txt”和“2.4.2更新说明.txt”。

一、安装与启动

客户端适用于 Windows 10/11（64 位），已携带运行依赖和本机 CPU 图纸识别组件。
无需另外安装 Python、PyTorch 或 CUDA，也不要求 NVIDIA 显卡。

安装版：运行 HydraulicWorkbenchStudio-2.4.6-Windows-x64-Setup.exe，按向导安装，
然后通过桌面或开始菜单启动。安装版和免安装版使用相同账户及计算功能。

免安装版：先完整解压 HydraulicWorkbenchStudio-2.4.6-Windows-x64.zip，
再运行 HydraulicWorkbenchStudioSecure.exe。不要在压缩包预览窗口内运行。
请保留整个程序文件夹，不要单独移动主程序或删除 auth_distribution.json、
HydraulicWorkbenchUpdater.exe、recognition_runtime 及其他运行库。

二、注册、登录与授权

1. 首次使用时，在登录窗口点击“没有账户？提交注册申请”。
   账户名为 3～32 个字符，可用中文、字母、数字、下划线、点、短横线或 @，不能含空格。
   密码为 6～20 个字符，不能使用程序拒绝的常见密码或包含完整账户名；确认密码须一致。
2. 填写手机号或邮箱（至少一项，建议填邮箱，用于自助找回密码），阅读《用户须知与隐私说明》
   并勾选同意，再提交申请。申请需要制作方审核；可通过已有联系渠道告知申请的账户名，不要发送密码。
3. 获批后联网输入账户名及密码，点击“安全登录”。已有账户直接使用，无需因更新重新注册。
4. “允许本机识别结果修正模型样本”默认关闭，不影响注册、登录及计算；
   勾选不会触发自动上传图纸或自动训练。之后可在“帮助 → 关于”中管理授权或删除本机样本。
5. 成功在线登录后，软件保存当前 Windows 用户的本机离线授权。后续仍点击“安全登录”；
   服务连接失败时，程序尝试使用有效的本机离线授权，没有单独的离线登录按钮。
   离线使用受授权有效期约束；换电脑、换 Windows 用户或删除授权缓存后需重新在线登录。
6. 注册、首次登录、找回密码、密码更改、账户名变更、反馈发送及授权续期需要联网和服务支持。
   修改密码和更改账户名位于右上角头像菜单“修改密码…”，提交后经管理员审批生效。
   忘记密码时点击登录页“忘记密码？找回密码”，输入账户名和注册邮箱获取 6 位验证码，
   验证通过后直接设置新密码。
7. “记住用户名”和“记住密码”可自行选择，记忆信息受当前 Windows 用户保护；
   共用电脑不建议记住密码。

三、开始计算

建议先按“建立模型 → 参数检查 → 求解计算 → 结果分析”运行随包示例。

管网示例：选择“文件 → 打开工况…”，打开 configs/longitudinal_network_test.json，程序识别为
管网工况并进入网络计算。在“网络计算 → 计算设置”保留默认 MOC，点击“打开计算检查中心”，处理阻止项后点击
“运行 MOC 全网计算”，或在网络计算页按 F5。计算在后台运行，状态栏显示进度，可点“取消”或按 Esc。
完成后自动进入“结果输出”，在“纵断面校核”页签查看 HGL 包络、超限区段及监测位置时程。

单管示例：同样用“文件 → 打开工况…”打开 configs/longitudinal_single_pipe.json，程序进入单管模型；
在单管页面点“计算检查中心”，再点“开始 MOC 计算”或按 F5；完成后自动进入“结果浏览”。
“文件 → 保存当前工况…”（Ctrl+S）按当前页面保存单管或管网工况。管网结果归档 .hnr 可从
“结果输出”页的“加载结果归档…”重开。更详细的 CSV、纵断面和比较操作见 LongitudinalReadme.txt。

计算前应核对真实几何、波速、摩阻、边界、网格、时间步、输出间隔及资源需求。
工况、剖面或压力限值修改后，已有结果仍对应上次运行输入，需要重新计算。
未设置压力限值不代表校核通过；区段长度是统计窗内曾超限位置集合的长度，
不是同时超限长度，也不是超限持续时间。

轮灌与监测布设：在项目浏览器点击“监测布设与轮灌”，通过“载入管网 ▾”打开随包示例或导入自己的
管网和田块数据；也可在“网络计算 → 拓扑参数”点“送往监测布设与轮灌”，或在规划页点“从网络计算导入”，
直接使用网络计算中打开的管网（基础需水量大于 0 的节点自动成为出水口，拓扑修改后自动同步）。核对“输入与约束”“约束与误差设置”后，点击“1 计算轮灌”，再点击
“2 校核误差并布点”，查看轮灌方案、所需最少的压力计/流量计位置及逐轮误差界。
需要设计管径时，在“管径与轮灌设计”页填写内径与成本目录，在“计算设置”中选择全局最优
（优先级或 Pareto 模式）或采样搜索，生成方案后“选择并冻结”，再进行误差校核与布点。
结果和最优性证书可通过“导出结果”保存为 JSON/CSV；证书会标明是否已证明最优及当前上下界。
联合搜索和误差布点在底部状态栏显示进度，并可随时取消。

四、图纸、拓扑与界面

图纸识别入口为“文件 → 导入管网图纸（PNG/JPG/JPEG/DXF）…”或“网络计算 → 拓扑参数”的
“选择图纸并识别…”，在本机 CPU 执行；组件状态异常时可在“组件详情”中“重新检查组件”。
先预览并人工复核节点、管段、交叉线连接、水源及比例尺，再导入并补全水力参数。
候选拓扑和默认参数不能代替真实工程数据。识别组件首次加载可能较慢，
可查看阶段和耗时并取消任务；有效本机授权范围内可离线识图。

拓扑工具栏的“添加文字”支持多行标注、单击选中、双击编辑、拖动位置和右键样式设置。
选中节点、管段或标注后按 Delete 键可删除；Ctrl+Z 撤销上一步拓扑修改，Ctrl+Y 重做，
撤销结果自动写回工况。识别结果校核窗口中同样可用 Delete 和 Ctrl+Z/Ctrl+Y。
“导出拓扑”输出完整场景的 PNG、JPG 或 AutoCAD 2004 格式 DWG。
图片支持 72–1200 DPI；DWG 为矢量文件，不使用 DPI，字体显示取决于接收电脑。

菜单栏为“文件 / 求解 / 结果 / 界面 / 帮助”。常用快捷键：Ctrl+O 打开当前工况、Ctrl+S 保存当前工况、
F5 运行当前工况、Esc 取消正在运行的任务、Ctrl+1 单管模型、Ctrl+2 单管结果浏览；“当前工况”跟随
所在页面切换单管或管网。系统概况的四张卡片实时显示分析域、模型检查、计算结果是否与当前参数一致
和核心验证，并提供功能模块入口和最近文件。
登录背景视频播放后停留末帧，在登录窗口向上滚动鼠标滚轮可重播。
右上角头像菜单的“更换头像…”支持静态 PNG、JPG/JPEG、WebP、BMP，
可用“恢复默认头像”撤销。头像按账户保存在本机，不跨设备同步。
“设置”页（顶栏齿轮或项目浏览器底部“⚙ 设置”）的“界面语言”可选择简体中文或 English，
切换后界面重新打开，登录状态保留；同页可打开模型验证和日志目录。

五、更新与数据保护

GitHub Release 与软件内更新服务分别发布。本版 2.4.6 同时在 GitHub Release 和软件内更新提供，
以“软件更新…”窗口中实际显示的版本和状态为准（2.4.6 在右上角头像菜单“软件更新…”，
2.4.5 及更早在头像菜单“设置 → 软件更新…”）；已安装旧版本的用户可在软件内直接升级，
也可下载本版安装程序覆盖安装。升级后首次登录需重新阅读并勾选更新后的《用户须知与隐私说明》。
有可用版本时可选择“检查更新”“下载并安装更新”，并按提示完成。

更新前保存工况，备份工程和结果。更新期间不要强制结束更新器或关机。
正常软件内更新保留 outputs、auth_distribution.json 和当前 Windows 用户的授权及设置；
其他自建文件建议放在程序目录之外，不要依赖更新器保留任意文件。
服务暂时不可达不影响具有有效本机授权的账户继续离线使用。

手动升级可运行本版安装程序，或将本版完整 ZIP 解压到新文件夹。
确认新版可打开工况和结果后再整理旧程序，不要混合覆盖少量新版文件。
安装、解压或换设备不要求重新注册；新设备仍需使用原账户在线登录。
工况、报告和结果以保存或导出时选择的位置为准。复制程序文件夹不会转移本机授权。
安装版卸载及数据保留说明见 InstallerReadme.txt。

六、适用范围与反馈

不同 MOC/FVM 路径支持的边界及物理模型有所区别，程序不会自动将不兼容的 FVM 工况
改用 MOC。请在计算检查中心处理阻止项，并查阅“帮助 → 模型适用范围”。
本版不求解泵停机、空化、液柱分离或防护设备；越过汽化阈值后，单相模型结果不能
继续作为有效物理结论。软件用于科研、教学和辅助分析，实际工程应用需复核输入与适用范围。

在线登录后点击顶栏 ✉ 图标提交反馈，可附文字及最多 4 张静态 PNG、JPG、WebP 图片；
截图后在反馈窗口按 Ctrl+V 或点“粘贴截图”即可附上。
审批中心回复后，登录时 ✉ 图标出现提示点；在反馈窗口点击“查看回复”，
或在账户菜单选择“我的反馈与回复…”查看全部反馈及回复（需在线登录及服务功能支持）。
头像菜单“账户信息…”中可申请绑定或修改手机号和邮箱，管理员审批通过后生效。
顶栏机器人图标是 AI 小助手：可询问功能位置、操作步骤、参数含义和报错处理，
提问时可附带当前页面、工况摘要、最近的检查结果和报错原文，解决不了时一键转为用户反馈。
图片可在发送前预览和移除，需要服务功能支持；不支持时可移除图片提交文字。
日志入口为项目浏览器底部“▤ 日志”或“设置”页“打开日志目录”。也可通过 GitHub Issues 反馈：
https://github.com/Iqx-nwafu/hydraulic-workbench-studio/issues
请提供软件版本、操作步骤、错误提示及可公开的最小示例；不要公开密码、授权缓存、
会话信息或未经许可披露的工程资料，分享日志前先检查其中的个人和项目信息。

七、下载与校验

官方 Release：https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases
请使用本版 SHA256SUMS.txt 核对下载的安装程序或 ZIP，来源不明或校验不一致时停止运行。

SHA-256 和更新元数据签名不等同于 Windows 代码签名，不要关闭安全防护来强行安装。

仅为公开仓库文件快照，不是软件源码或完整客户端。
