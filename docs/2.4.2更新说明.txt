有压管网瞬态水力仿真平台 2.4.2
Windows x64 客户端更新说明
日期：2026-10-25

本版在 2.2.0 的单管/管网 MOC、FVM、真实纵断面、压力校核、关阀方案比较和结果报告能力基础上，完善拓扑图交付、登录体验及工作台操作。

一、相较 2.2.0 的新增功能

1. 完整拓扑导出
   在管网拓扑工具栏点击“导出拓扑”，选择 PNG、JPG 或 AutoCAD 2004 格式 DWG。
   导出包含当前完整节点、管段及文字标注，也包含视窗外的内容。
   图片支持 72–1200 DPI 和图幅宽度设置；DWG 为可编辑矢量图，不使用 DPI。
   DWG 的文字显示取决于接收电脑安装的字体。

2. 可编辑文字标注
   点击“添加文字”后，在拓扑上单击放置并输入文字，支持多行内容。
   单击已有文字可编辑；拖动可调整位置；右键可修改字体、字号、颜色或删除。
   标注随拓扑保存并参与导出。单独修改标注不改变水力模型，也不会使已有结果过期。

3. 高清动态登录界面
   采用高清海洋视频背景，重新调整品牌文字及下方标语的布局。
   视频播放一次后停留在末帧；鼠标位于登录窗口时，向上滚动滚轮可从头重播。
   调整解码和显示调度，连续滚轮操作会合并处理，重播结束后仍保留末帧。

4. 本机账户头像
   在右上角头像菜单选择“更换头像…”或“恢复默认头像”。
   支持静态 PNG、JPG/JPEG、WebP、BMP 图片，头像按账户独立保存在本机，不跨设备同步。

5. 带截图的用户反馈
   点击右上角“反馈”，填写说明后可添加最多 4 张静态 PNG、JPG 或 WebP 图片。
   发送前可预览和移除图片；点击发送后才提交当前文字及附件。
   图片反馈需要在线登录及服务功能支持；不支持时可移除图片提交文字反馈。

6. 系统概况及交互优化
   系统概况集中展示分析域、模型检查、计算结果、求解方法和当前工况参数。
   提供“建模 → 检查 → 计算 → 结果 → 报告”五步操作入口，并根据当前状态提示下一步。
   小窗口下调整排列并支持滚动查看。
   工作台顶栏标题重新对齐，按钮统一圆角外观、悬停过渡与按下、禁用等状态反馈。

二、下载与使用

Release 页面：
https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases/tag/v2.4.2

首次安装推荐：HydraulicWorkbenchStudio-2.4.2-Windows-x64-Setup.exe
免安装客户端：HydraulicWorkbenchStudio-2.4.2-Windows-x64.zip
文件校验：SHA256SUMS.txt

客户端适用于 Windows 10/11（64 位），已携带运行依赖和本机 CPU 图纸识别组件。
无需另装 Python、PyTorch 或 CUDA。免安装版需完整解压，再运行 HydraulicWorkbenchStudioSecure.exe。
不要单独移动主程序，也不要在压缩包预览窗口内运行。

本仓库不公开软件源代码。GitHub 自动生成的 Source code (zip/tar.gz) 及 Code → Download ZIP
只包含公开仓库文件，不是软件源码或可运行客户端。

三、已有用户升级

升级前保存工况并备份工程及结果。已有账户继续使用，无需重新注册。
可运行本版安装程序；也可将完整 ZIP 解压到新文件夹，确认能打开工况和结果后再整理旧程序。
不要将少量新版文件混合覆盖到旧程序目录。

GitHub Release 与软件内更新服务分别发布。GitHub 已提供 2.4.2 下载，不代表软件内“检查更新”
已同步提供该版本；请以“设置 → 软件更新…”窗口的实际显示为准。
新设备首次登录需要联网；原设备离线使用仍受本机授权有效期约束。

四、计算与数据说明

本版保留 2.2.0 的基本数值模型和计算流程。不同求解方法支持的边界与物理模型不同，
请先执行工况检查，并查阅“帮助 → 模型适用范围”。

修改几何、边界、真实纵断面或压力限值后，需要重新计算。图纸识别结果及水力参数须人工复核。
本版不求解泵停机、空化、液柱分离或防护设备；实际工程应用需核验输入和模型适用范围。
