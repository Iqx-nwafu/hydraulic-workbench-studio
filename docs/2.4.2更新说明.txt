有压管网瞬态水力仿真平台 2.4.2
Windows x64 客户端更新说明
日期：2026-10-26（替换 2026-10-25 的 2.4.2 安装包）

本版在 2.2.0 的单管/管网 MOC、FVM、真实纵断面、压力校核、关阀方案比较和结果报告能力基础上，
新增“监测布设与轮灌”工作域，完善拓扑图交付、登录体验及工作台操作。

一、相较 2.2.0 的新增功能

1. 完整拓扑导出
   在管网拓扑工具栏点击“导出拓扑”，选择 PNG、JPG 或 AutoCAD 2004 格式 DWG。
   导出包含当前完整节点、管段及文字标注，也包含视窗外的内容。
   图片支持 72–1200 DPI 和图幅宽度设置；DWG 为可编辑矢量图，不使用 DPI。
   DWG 的文字显示取决于接收电脑安装的字体。

2. 可编辑文字标注
   点击“添加文字”后，在拓扑上单击放置并输入文字，支持多行内容。
   单击已有文字可编辑；拖动可调整位置；右键可修改字体、字号、颜色或删除。
   标注随拓扑保存并参与导出。单独修改标注不改变水力模型，也不会使已有结果过期。

3. 高清动态登录界面
   采用高清海洋视频背景，重新调整品牌文字及下方标语的布局。
   视频播放一次后停留在末帧；鼠标位于登录窗口时，向上滚动滚轮可从头重播。
   调整解码和显示调度，连续滚轮操作会合并处理，重播结束后仍保留末帧。

4. 本机账户头像
   在右上角头像菜单选择“更换头像…”或“恢复默认头像”。
   支持静态 PNG、JPG/JPEG、WebP、BMP 图片，头像按账户独立保存在本机，不跨设备同步。

5. 带截图的用户反馈
   点击右上角“反馈”，填写说明后可添加最多 4 张静态 PNG、JPG 或 WebP 图片。
   发送前可预览和移除图片；点击发送后才提交当前文字及附件。
   图片反馈需要在线登录及服务功能支持；不支持时可移除图片提交文字反馈。

6. 监测布设与轮灌
   在项目浏览器点击“监测布设与轮灌”，载入管网和田块需水量，在“输入与约束”“约束与误差设置”中
   核对首部压力、供水上限、最低压力、流速上下限和需水量。
   “1 计算轮灌”依次优化总灌溉时长、组内压力平均绝对偏差和压力方差，每轮均校核流速、压力和计划水量。
   “2 校核误差并布点”在轮灌方案冻结后，按仪表误差、估计容限和验证域给出所需最少的压力计、
   流量计数量及位置，并逐轮校核全网压力和管段流量误差。图中圆形为压力计、三角形为流量计。

7. 管径与轮灌联合设计
   可通过“载入管网 → 导入拓扑（管径待定）”或“当前管网联合设计”开始；也可在固定管径规划中“启用管径设计”。
   在“内径与成本目录”编辑或导入 CSV（option_id,inner_diameter_mm,cost_per_m），
   点击“生成初始方案并联合搜索”，可查看“管径布置图”并导出 SVG。
   选中方案后点击“选择并冻结”，系统重新校核管径、轮组、时长和硬约束，之后再进行误差校核与布点。

8. 全局最优求解与最优性证书
   “计算设置”默认使用全局最优（精确联合模型）：
   优先级模式先求最短总时长，再按所选第二目标依次优化；多目标模式给出投资—时间—压力均匀性 Pareto 方案。
   结果附最优性证书，记录各目标的上下界、间隙和证明状态，可在“最优性证书”窗口查看并导出 JSON/CSV。
   传感器数量或成本可纳入联合决策；“采样搜索（原方法）”保留在同一窗口供选用。
   规模较大、时限内未闭合时，证书如实给出当前上下界，不把可行方案标为已证明最优。

9. 结果保存与导出
   “保存规划”保存可再次打开的输入 JSON；“导出结果”保存轮灌方案、传感器布设、逐轮误差校核、
   联合设计及证书文件（JSON/CSV）。随包示例位于 data/irrigation_examples/。

10. 联系方式绑定
    在“账户信息”中提交手机号和邮箱绑定申请，管理员审批通过后生效；审批前原绑定继续有效。
    该功能需要在线登录。

11. 系统概况与最近工程文件
    系统概况集中展示分析域、模型检查、计算结果、核心验证和当前工况参数，
    提供“建模 → 检查 → 计算 → 结果 → 报告”五步入口、快速进入计算模块和下一步提示，
    并列出最近打开或保存的工况与管网配置。小窗口下自动调整排列并支持滚动。

12. 计算资源与界面
    原生计算可使用全部可用 CPU 核心，独立轮次搜索并行执行；联合搜索、冻结复核、误差布点等
    长时间计算统一显示在底部进度栏，并可随时取消。
    优化了若干界面布局；按钮统一圆角外观、悬停过渡与按下、禁用等状态反馈。

三、已有用户升级

升级前保存工况并备份工程及结果。已有账户继续使用，无需重新注册。
可运行本版安装程序；也可将完整 ZIP 解压到新文件夹，确认能打开工况和结果后再整理旧程序。
不要将少量新版文件混合覆盖到旧程序目录。

GitHub Release 与软件内更新服务分别发布。2026-10-26 起，软件内更新已同步提供本版 2.4.2，
旧版本客户端可在“设置 → 软件更新…”检查并安装；请以该窗口的实际显示为准。

2026-10-25 已从 GitHub 安装 2.4.2 的用户：当天的安装包不含“监测布设与轮灌”等功能，
由于版本号相同，软件内更新不会再次提示。请下载最新安装程序直接覆盖安装，
或将最新 ZIP 解压到新文件夹；账户、授权和输出目录保留。
新设备首次登录需要联网；原设备离线使用仍受本机授权有效期约束。

四、计算与数据说明

本版保留 2.2.0 的瞬态基本数值模型和计算流程。不同求解方法支持的边界与物理模型不同，
请先执行工况检查，并查阅“帮助 → 模型适用范围”。

修改几何、边界、真实纵断面或压力限值后，需要重新计算。图纸识别结果及水力参数须人工复核。
本版不求解泵停机、空化、液柱分离或防护设备；实际工程应用需核验输入和模型适用范围。
轮灌与布点结果只对应所输入的管网、田块、约束和误差设置；最少传感器数量针对已冻结方案和声明的误差域。
成本目录中的示范值为相对指数，实际设计请填写真实报价。
