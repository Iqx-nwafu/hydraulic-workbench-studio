# 渠道共享与时间配对使用说明

适用版本：2.4.10 及以后（含 2.5.0）　功能首发：2026-11-13

从项目浏览器打开“灌溉站渠道监测（试）”。渠道所有者与接收者都需使用 2.4.10 或更高版本，并在线登录各自的 HWS 账号。

## 把自己的渠道共享给另一个账号

1. 在自己的监测页配置站点、闸门和测点；需要查看闸门或下发指令时，先完成“连接设置”中的厂家连接。水位、流量来自这座站点的现场转发包，或所有者本机已导入的数据；本机导入的历史不会因为共享而自动上传。
2. 点右上角“共享渠道…”，在“共享当前渠道”中填写接收者的 **HWS 用户名**，选择权限，点“共享给此账号”。共享范围是当前站点配置中的渠道、闸门和测点，不只是左栏选中的一座闸门。
3. 接收者在自己的“共享渠道…”窗口点“刷新列表”，从“我可访问的共享渠道”选中渠道，点“打开共享渠道”。它会打开独立监测窗口，不覆盖接收者自己的站点、连接或数据。

| 权限 | 接收者可以做什么 |
| --- | --- |
| 查看（viewer，默认） | 查看共享监测与历史、导出数据；不能立即采集或下发指令。 |
| 测控（operator） | 在所有者已配置厂家连接时，可以立即采集和下发支持的闸门指令。授予时需要确认，请授予负责现场操作的账号。 |

接收者无须填写厂家 URL、令牌或现场串口配置。共享窗口不能修改厂家连接、导入站点或测点文件、再转授账号，也不能修改厂家回调地址；这些由所有者管理。服务端逐次检查权限，接收者本地设置不能提升权限。

共享时，站点配置和时间配对设置保存到平台云端，归所有者的 HWS 账号管理；厂家连接凭据在服务器密封保存，不下发给接收者。共享窗口通过平台访问授权数据。

## 现场转发包与后续维护

- 已开通现场远程同步：共享沿用原站点，**不会轮换上传密钥，原工控机转发包继续使用**，不用为了共享重新保存转发包。
- 尚未开通：首次共享会创建现场同步站点；用“保存新站点转发包…”生成包，并按包内 README 安装到工控机。共享操作本身不会安装或启动现场采集。
- 改过渠道、测点关联、时间配对开关、容差或厂家连接：所有者点“更新共享配置”；接收者在独立窗口点“刷新共享资料”，或重新打开共享渠道。修改本机配置不会自动发布给其他账号。
- 撤销：所有者在成员表选中账号，点“撤销所选成员”。撤销后新访问和测控请求会被拒绝；接收者窗口收到授权失效后停止实时操作。已经下载的历史和导出文件不会被远程删除。

## 自动把水位、流量配到闸门采样时刻

1. 在“连接设置 → 测点表”填好测点与闸门的关联、闸前或闸后位置；没有关联的测点不能参与这座闸门的配对。
2. 在“连接设置”的数据区域保留“自动按闸门采样时刻配对水位与流量”。默认开启，“允许早于闸门”为 **300 秒**；可设为 0–900 秒，0 表示必须同秒。点底部“保存”。
3. 选中闸门，查看详情中的基准时间、数据龄、配对状态；展开“配对时间明细”核对各路库内时间、早于基准的秒数，以及测点之间的采样跨度。

软件以最新一条闸门采样记录的库内时间为基准，每路测点取**不晚于基准、且在容差内的最近记录**。例如闸门为 10:00:00、容差为 300 秒，可以配到 09:58:00；09:54:00 超差，10:01:00 晚于基准，均不能用来配这条闸门记录。没有合适记录就留空，不用其他“最新值”补上。

“配对齐全”只表示已关联的各路找到了容差内记录，还要看闸门数据是否过旧。配对不插值、不移动时间、不修改设备时钟，也不保证各设备同时采样。库内时间已按既有导入或远程同步流程处理，不能当作逐条保留的设备原始时钟；采样与入库时间差很小，也不能单独证明设备时钟准确。

关闭自动配对后，详情恢复显示各路自己的最新记录，并提示“各路最新记录不代表同一采样时刻”。闸前、闸后水深差也要结合采样跨度阅读。控制窗口和调整指令确认框会显示相同的基准与配对信息，供操作时核对；配对不增加控制权限，也不会自动发指令。

## 选对导出方式

- **导出配对快照**：保存当前闸门基准、各路库内候选时间、时间差、匹配状态、数据龄和配对后的实测值；超差的候选时间可供追查，其测量值留空。适合记录一次操作时的读数依据。
- **导出对齐表**：按趋势时间窗生成历史分析表，允许按既有规则插值或保持开度，适合分析历史过程；其中的插值结果不等于同时采集的实测快照。
- **导出 CSV**：保留趋势数据的长表形式。

渠道水量平衡中的“自动估计滞后”用于分析水流传播过程，不能用来证明或修正设备时钟同步。下发后若提示“结果未知”，先核对开度回读和指令记录，不要直接重复下发。
