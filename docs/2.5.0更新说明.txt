有压管网瞬态水力仿真平台 2.5.0
2026-11-20

请先保存打开的工程，再从右上角账户菜单选择“软件更新…”。检测到 2.5.0 后，按提示下载安装并重新打开平台。

一、新增功能

1. AI 小助手支持 Bug 截图
   可添加图片、粘贴截图或在输入框按 Ctrl+V，发送前查看缩略图、放大预览或移除。每个问题最多 4 张静态 PNG/JPG/WebP，压缩后单张不超过 2 MB、合计不超过 6 MB；客户端会缩放过大图片并移除图片元数据。图片由用户主动选择，截图中的账号、项目信息仍需在发送前检查和遮盖。小助手结合问题、截图和获准的页面信息分析报错。

2. 工作组好友与聊天
   顶栏 AI 小助手左侧新增“工作组”。按注册用户名发送好友申请，对方同意后进入纵向好友列表；头像右下角用绿点或灰点标记最近在线状态。双击好友打开一对一聊天，支持文字和表情，有未读消息或待接收资料时显示提醒。好友页提供搜索、“好友管理器”“新朋友”入口，好友统一显示在可折叠的“我的好友”栏，原“特别关心”联系人也在其中；可设置本机备注，按当前账号分别保存。列表可预览最近消息、共享名称及待接收资料。“群聊”页签和“新群聊”入口显示未开放说明，本版不创建群聊。

3. 工作组工程分享与独立接收
   聊天窗的文件夹按钮提供“平台工程文件”“当前设置参数”“已计算数据”。可选择平台 JSON 工程、.hnr 结果归档或 .hws-share.zip 共享包，单份传输不超过 32 MiB。好友列表和聊天窗均可用 √ 接受、× 拒绝；拒绝会通知发送者。接受前校验资料，成功后保存到本账号的独立工程目录并打开新工作台，当前工作台的草稿保持原样；可在聊天中再次查看已经接收的工程。
   当前参数和已计算数据快照包含其对应的工程输入；管网共享包附带计算所需的 INP、拓扑等资料。灌水量识别快照带上规范化影像、田块、作物、实测标定、管网布置与节点匹配资料，可在接收者独立工程继续识别、标定及需水匹配；选择本地识别项目时由发送端打包所需影像，不引用发送者电脑的原目录。直接分享 .hnr 用于结果归档浏览，不等同于完整可继续编辑的工程；需要修改参数并继续计算时，优先发送参数/数据快照或带齐依赖的工程包。影像和结果较大时须先控制共享包体积。

4. 监控、个性化与云端记忆
   “设置”和小助手窗口提供“监控功能”，包含三个独立开关：
   - AI小助手监控功能：提问时读取当前页面、已填参数、检查结果和最近报错，结合当前状态回答设置问题；需要明确目标时先询问用户目的。不会后台录屏、读取其他应用或自动上传工况文件。
   - 允许监控功能用来提升AI小助手的个性化回答：控制个人历史记忆的创建与使用，关闭后仍可在监控开启时分析本次页面。
   - 允许小助手记忆上传云端，用来提升大模型的整体处理性能：控制问答内容与个人记忆的云端保留，以及解决方法的提交。
   新版登录须知明确披露上述默认开启项、主动附图、服务商处理范围及删除方式；接受后按新账户默认值开启，已经保存的关闭选择不会因重新登录或更新须知而被重置。本机开关可离线修改；在线时可查看或删除本账号云端记忆。删除还会清理本账号已保留的问答文本和已提交的解决方法，必要的次数统计与审计元数据继续保留。

5. 已解决方法进入审核知识库
   用户确认问题已解决后，可点“已解决，提交方法”，填写实际有效的方法并删除私密信息。提交内容进入管理员审核，只有审核通过的脱敏问题和解决方法才用于其他用户类似问题的知识检索。个人历史记忆不跨账号共享；这项改进属于知识检索增强，不代表训练或微调底层大模型。

6. 自助修改账户名
   点击右上角头像菜单中的账户名一行或“修改账户名…”，填写新账户名与当前密码后保存，无需管理员审批。服务器核对已注册账户及保留名称，大小写或 Unicode 等价名称也不能重复；账户名须为 3～32 个字符，不能与当前账户名相同。改名直接写入审批中心账户资料，本机刷新用户名、登录会话、离线授权和记住的账户，账户身份、头像、好友、渠道共享权限与已保存工程继续保留。其他设备的旧会话会失效，需要使用新账户名重新登录。
   新版审批服务将改名与新会话签发作为同一事务处理，关闭其他操作的自动审批也不影响自助改名。旧版审批服务开启自动处理时可兼容改名并自动续登；不支持直接改名的旧服务会明确提示升级，不会悄悄提交人工审批申请。若旧服务改名已完成而续登失败，会提示保存工程后以新名重新登录。
   若提交后网络中断、未能收到确认，界面会显示“改名结果未确认”，保留工程并停止使用旧在线令牌，不自动重复提交。保存工程后先尝试新账户名在线登录，提示账户不存在时再使用原账户名。

二、改进与修复

1. 审批中心启动、关闭、刷新及 AI 设置读取、保存、连接检查改为后台任务，界面保留加载状态；慢响应、关闭窗口或取消启动时不再阻塞界面。晚到的读取结果不会覆盖正在编辑的表单，配置已保存但随后刷新失败时会分别说明保存结果和读取状态。
2. 小助手可以继续使用管理员配置的 Kimi。若 GPT 返回 HTTP 403 / unsupported_country_region_territory，审批中心会提示管理员核对服务商支持的部署地区。
3. 审批端反馈内容、回复记录和回复输入区增加与主题一致的文本边界与间距，便于区分只读内容和可输入区域。
4. 注册验证码增加 60 秒重新发送倒计时；服务端同时校验同一邮箱的冷却时间，重开窗口或并发请求也不能绕过。不同邮箱独立计时，邮件投递失败仍保留短时冷却，避免反复点击触发连续发送。
5. 项目浏览器拖动范围随窗口宽度调整，限制侧栏过度占用主工作区；缩小、放大或重新打开窗口时恢复合适的侧栏宽度，原有 Ctrl+B 展开/收起继续使用。
6. Windows 任务栏窗口明确使用平台的新图标与应用身份，统一客户端、审批端及重新打开窗口的显示，减少源码运行入口显示宿主程序图标的情况。
7. 问题与页面文字尽量隐藏本机目录、联系方式和明显凭据；服务端保存的关闭选择不会被旧客户端或旧请求重新打开。设置关闭、云端删除与在途回答之间使用版本校验，晚到回答不能重新写回已删除的问答和记忆。
8. 修复拓扑画布缩放后、下一次重绘尚未到来时的命中坐标：节点、管段、框选、编号与文字标注按当前视图更新，避免快速操作使用上一次绘制的位置。
9. 修复 SI 小助手将短暂网络失败或回答超时误报为“管理端可能尚未开启”的问题：只读服务检查遇到临时故障时有限重试，同一次提问复用能力检查结果；分别提示连接失败、连接中断、安全证书异常和回答超时。已提交的问题不自动重发，避免重复占用问答次数。
10. 修复共享渠道面板初次加载后点击“打开共享渠道”没有打开窗口的问题：加载后默认选中首个可访问渠道，刷新时按渠道标识保留选择；列表为空、没有选择或加载期间禁用打开按钮。共享查看和测控权限继续由服务端校验。
11. 主界面的“设置”统一保留在左下角，移除左上角“界面”菜单和右上角头像菜单中的重复入口；账户菜单仍提供账户信息、头像、软件更新和退出登录。

三、安全与授权

- 冻结版 Studio 在打开登录窗口前核对平台模块。程序文件损坏或版本混用时，请用同一版本的完整分发包修复。更新器在替换文件前复核发布清单和实际内容。
- 工作台在使用中也会检查授权有效期。授权失效时，可用打开该工程的账户联网续登，继续处理内存中的工程。桌面或科研命令行收到明确的账户停用、过期或设备拒绝后，该账户在本机的旧离线授权也需重新验证。
- 审批中心按授权中签署的设备标识分配两个名额。首次使用新的 Windows 用户配置可能占用一个新名额。管理员释放指定设备后，该设备的在线会话立即失效，对应名额在原离线授权到期后归还。
- “其他灌区”里的 HTTP 地址以普通网页打开。自动填写已保存的第三方账号密码需要 HTTPS，更换登录站点后需重新输入密码。

四、兼容说明

1. 工作组、图片分析和云端记忆管理需要配套新版审批服务。连接仅支持文字问答的旧服务时，小助手常驻提示“审批服务尚未升级，当前可使用文字问答；图片和云端记忆管理待服务升级”。允许现有问答保留且未附图时继续使用原服务的文字问答；关闭云端记忆后，旧服务无法保证不保留问答，因此会明确阻止发送。图片不会被悄悄丢弃，记忆管理也不会伪装为已完成。
2. 新工作组工程按账号隔离，接受的是独立副本，不是多人同时编辑或实时合并。缺少依赖、校验失败、取消导入时保持待接收状态，可修正资料后重试；已经过期的计算结果不能代替新参数下的重新计算。
