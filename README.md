# 有压管网瞬态水力仿真平台 · 2.4.4

面向城市供水与灌溉输配水的一维瞬态水力分析平台，支持单管、分支及环状管网的特征线法（MOC）和有限体积法（FVM）。从参数建模、图纸识别与拓扑复核，到瞬态计算、真实纵断面与压力校核、关阀方案比较、轮灌规划与监测布设和结果报告，在同一工作台内完成分析。

本仓库提供 **Windows 客户端、版本说明和使用文档，不公开软件源代码**。普通用户无需安装 Python 或配置开发环境。

**[下载 2.4.4 安装程序](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases/download/v2.4.4/HydraulicWorkbenchStudio-2.4.4-Windows-x64-Setup.exe)** · **[下载完整免安装 ZIP](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases/download/v2.4.4/HydraulicWorkbenchStudio-2.4.4-Windows-x64.zip)** · **[查看本版 Release](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases/tag/v2.4.4)**

已安装旧版本的用户也可在“设置 → 软件更新…”直接升级到 2.4.4；本版更新要点见下文及 [2.4.4 更新说明](docs/2.4.4更新说明.txt)。

## 平台功能

| 能力 | 可以完成的工作 |
| --- | --- |
| 单管与管网瞬态计算 | 使用 MOC 或 FVM 分析压力、流量及波动传播；支持分支、环网、机械阀门过程与不同管道参数 |
| 建模与计算检查 | 设置几何、材料、波速、摩阻、边界及初始状态；使用稳态初始化，检查参数、网格、时间步和资源需求 |
| 图纸识别与拓扑编辑 | 在本机识别 PNG/JPG/JPEG/DXF 图纸，复核节点、连接、水源和比例尺，补全真实水力参数后导入模型 |
| 真实纵断面与压力校核 | 导入或编辑管中心高程，查看沿线最大/最小 HGL 包络、监测位置时程及工程压力超限区段 |
| 关阀方案比较 | 对比不同阀门动作方案，检查已消除、仍超限和新增的区段，并导出同位置压力及阀门时序 |
| 结果分析与报告 | 查看时程、空间分布、动画、风险提示和守恒信息；保存工况、结果归档、图表及报告 |
| 拓扑图交付 | 添加可编辑文字标注，输出完整拓扑的 PNG、JPG 或 DWG 文件 |
| 监测布设与轮灌 | 计算满足流速、压力和水量约束的轮灌方案；在设定误差下确定所需最少的压力计、流量计及位置；可联合设计管径与轮灌，并输出最优性证书 |
| AI 小助手 | 询问功能位置、操作步骤、参数含义和报错处理；可结合当前页面与工况参数回答，解决不了时一键转为用户反馈 |
| 中英文工作台 | 按“建模 → 检查 → 计算 → 结果 → 报告”组织操作，支持简体中文和 English |

不同求解方法支持的物理模型和边界条件有所区别。程序会检查当前组合的适用范围；详细说明可在“帮助 → 模型适用范围”查看。

## 2.4.4 更新要点（相比 2.4.2）

1. **AI 小助手**：右上角机器人按钮，可询问功能位置、操作流程、参数含义和报错处理；勾选“附带当前页面与工况”后结合当前情况回答（不发送工况文件、图纸和结果数据），无法解决时一键转为用户反馈。每个账户每天可提问 10 次，需在线登录。
2. **编号可拖动**：节点编号、管段编号可直接拖到合适位置，隐藏再显示、重新打开工况和导出时位置保持不变；右键“恢复自动位置”可还原。
3. **批量修改样式**：按住 Ctrl/Shift 多选文字标注和编号，可整体拖动，或右键“统一设置字体、字号与颜色”一次修改。
4. **导出编号可选**：导出拓扑时可选择是否包含节点编号、管段编号，导出的 PNG/JPG/DWG 与画面调整一致。
5. **拓扑编辑快捷键**：Delete 删除选中的节点、管段和标注；Ctrl+Z 撤销、Ctrl+Y 重做，结果自动写回工况；识别结果校核窗口同样支持。
6. **反馈回复**：制作方回复反馈后，登录时右上角提示未读，可在“我的反馈与回复…”中查看。
7. **节点三通设置更清楚**：节点参数对话框即时说明当前节点能否作为 90° 三通，“强制启用”不满足条件时直接提示原因。
8. **问题修复**：修复了图纸文件名或工程目录含中文时，保存工况、修改节点参数或开始计算提示 EPANET 302“cannot open input file”且无法继续操作的bug。

操作变化：文字标注改为**单击选中、双击编辑**。编号布局保存在拓扑文件中，旧版本打开时仍按自动位置显示。详细说明见 [2.4.4 更新说明](docs/2.4.4更新说明.txt) 和 [2.4.3 更新说明](docs/2.4.3更新说明.txt)。

## 2.4.2 相比 2.2.0 新增了什么

本版在 2.2.0 的数值计算与压力校核能力基础上，新增“监测布设与轮灌”工作域，并完善拓扑交付、登录体验和工作台操作。

1. **拓扑导出**：支持 PNG、JPG 和 AutoCAD 2004 格式 DWG，包含完整拓扑及文字标注，也包含视窗外内容。图片支持 72–1200 DPI 和图幅宽度设置；DWG 为可编辑矢量图。
2. **拓扑文字标注**：支持多行文字、单击编辑、拖动位置，以及字体、字号和颜色调整。标注随拓扑保存并纳入导出；单独修改标注不会使水力计算结果过期。
3. **高清动态登录**：采用高清海洋视频背景，调整品牌及标语排版。视频播放结束停留末帧；在登录窗口向上滚动鼠标滚轮，可从头重播。
4. **本机账户头像**：可在右上角头像菜单选择静态 PNG、JPG/JPEG、WebP 或 BMP 图片，也可恢复默认；头像按账户独立保存在本机，不跨设备同步。
5. **带截图的反馈**：反馈可添加最多 4 张静态 PNG、JPG 或 WebP 图片，发送前可预览和移除。图片反馈需要在线登录及服务功能支持；不支持时可移除图片提交文字反馈。
6. **轮灌规划与最少传感器布设**：在项目浏览器选择“监测布设与轮灌”，载入管网与田块需水量后计算轮灌方案，依次优化总灌溉时长和组内压力均匀性（平均绝对偏差、方差），每轮均校核流速、压力和计划水量。随后在设定的仪表误差和估计容限内给出所需最少的压力计、流量计数量及位置，并逐轮校核全网压力和管段流量误差。
7. **管径与轮灌联合设计**：可导入管径待定的拓扑，或将当前管网的骨干管径作为设计变量；按“内径与成本目录”同时设计管径和轮灌，查看管径布置图并导出 SVG。选中方案后“选择并冻结”，再进行误差校核与布点。
8. **全局最优求解与最优性证书**：在“计算设置”中可选优先级模式（先最短总时长，再依次优化其他目标）或多目标 Pareto 模式；结果附最优性证书，记录各目标的上下界、间隙和证明状态，可查看并导出 JSON/CSV。传感器数量或成本可纳入联合决策；原采样搜索方法保留为可选项。规模较大、时限内未闭合时，证书如实给出当前上下界，不把可行方案标为已证明最优。
9. **结果导出**：轮灌方案、传感器布设、逐轮误差校核及联合设计结果可导出 JSON 和 CSV；规划输入可保存后再次打开。随包提供示例管网及田块数据（`data/irrigation_examples/`）。
10. **联系方式绑定**：在“账户信息”中申请绑定手机号和邮箱，管理员审批通过后生效；审批前原绑定保持有效。
11. **系统概况与最近工程文件**：概况页集中展示分析域、模型检查、计算结果、核心验证和当前工况参数，提供五步分析流程、快速进入计算模块和下一步操作，并列出最近打开或保存的工况与管网配置。
12. **计算资源与界面**：原生计算可使用全部可用 CPU 核心，独立轮次搜索并行执行；长时间计算统一显示在底部进度栏并可随时取消。优化了若干界面布局，按钮统一圆角外观、悬停过渡和状态反馈。

详细操作见 [2.4.2 更新说明](docs/2.4.2更新说明.txt)。MOC/FVM、真实纵断面、压力区段与关阀方案比较是平台已有能力，本版更新不改变其基本物理模型。

## 注册与登录

首次注册和首次登录需要联网，且账户服务可用。软件账户独立于 GitHub 账户。

1. 在登录窗口点击 **“没有账户？提交注册申请”**，填写账户名、密码及确认密码。
2. 账户名为 3～32 个字符，可用中文、字母、数字、下划线、点、短横线或 `@`，不可含空格；密码为 6～20 个字符，不可使用程序拒绝的常见密码或包含完整账户名。
3. 阅读 **《用户须知与隐私说明》**，勾选同意后提交。出现“等待管理员审批”表示申请已提交；可通过已有联系渠道告知制作方申请的账户名，**不要发送密码**。
4. 获批后输入账户名和密码，点击 **“安全登录”**。已有账户直接登录，无需因版本更新重新注册。

“可选：本机保存识别修正样本（可撤回）”默认关闭，不影响注册、登录或计算；勾选不会触发自动上传图纸或自动训练。

成功在线登录后，程序会保存当前 Windows 用户的本机离线授权。后续仍点击“安全登录”；服务连接失败时，程序尝试使用有效的本机离线授权。离线使用受授权有效期约束，换电脑、换 Windows 用户或删除授权缓存后需重新在线登录。

注册、密码修改、账户名变更、发送反馈及授权续期需要联网。密码或账户名操作位于 **“设置 → 密码与安全…”**；“记住用户名”和“记住密码”可自行选择，共用电脑不建议记住密码。

## 第一次计算

建议先运行随包示例，熟悉 **“1 建模 → 2 检查 → 3 计算 → 4 结果 → 5 报告”**，再输入实际工程数据。

1. 登录后点击 **“模型 → 管网计算”**，再点 **“文件 → 打开当前工况…”**，选择随包 `configs/longitudinal_network_test.json`。应先进入管网页面，再打开管网工况。
2. 点击 **“模型 → 管网真实纵断面与压力限值…”**。示例管段 `P` 长 100 m，在 0、35、100 m 位置的管中心高程分别为 0、20、0 m，默认压力水头限值为 12～36 m。
3. 保留默认 MOC 设置，点击顶部 **“2 检查”**。查看阻止项及警告，存在阻止项时先修正。
4. 选择 **“求解 → 运行当前工况”** 或按 `F5` 开始计算。
5. 完成后进入管网 **“结果输出”**，在结果工作台选择 **“纵断面校核”**，查看管中心线、最大/最小 HGL 包络及超限区段，点击 35 m 高点查看压力时程。
6. 查看并导出报告；需要更改输出位置时，展开“目录与计算…”。通过 **“文件 → 保存当前工况…”** 保存可再次编辑的工况 JSON。

单管示例：先进入 **“模型 → 单管模型”**，再打开 `configs/longitudinal_single_pipe.json`。完整 CSV 导入、FVM 对照与方案比较步骤见 [纵断面使用示例](docs/LongitudinalReadme.txt)。

示例为人工构造的动态工况。HGL 为测压管水头，压力水头为 `HGL − 管中心高程`。包络记录计算内部步极值，极值可能发生在两个保存帧之间。

### 轮灌与监测布设示例

1. 在左侧项目浏览器点击 **“监测布设与轮灌”**，或在系统概况的“快速进入计算模块”中选择该项。
2. 点击 **“载入管网”**，选择随包示例（如“全管通水验证例”）。在“输入与约束”和“约束与误差设置”中核对首部压力、供水上限、最低压力、流速上下限及田块需水量。
3. 点击 **“1 计算轮灌”**，查看各轮开启单元、时长、供水量和压力统计；全部硬约束通过并取得证书后，才能进入下一步。
4. 核对仪表误差、估计容限和验证域后点击 **“2 校核误差并布点”**，在“传感器布设”和“逐轮误差校核”查看所需仪表位置及每轮误差界。图中圆形为压力计、三角形为流量计。
5. 需要同时设计管径时，在“管径与轮灌设计”页启用管径设计，填写“内径与成本目录”，在“计算设置”中选择求解方式后“生成初始方案并联合搜索”，再“选择并冻结”所选方案。
6. 通过“保存规划”保存可再次打开的输入，通过“导出结果”保存方案、布点、误差校核及最优性证书。

轮灌结果对应所输入的管网、田块、约束和误差设置；最少传感器数量只针对已冻结的方案和声明的误差域。成本目录中的示范值为相对指数，实际设计请填写真实报价。

## 使用自己的工程数据

| 步骤 | 操作要点 |
| --- | --- |
| 建模 | 选择单管或管网，录入几何、材料、波速、摩阻、初始条件、边界及阀门动作 |
| 图纸导入（可选） | 通过“文件 → 导入管网图纸（PNG/JPG/JPEG/DXF）…”识别，人工复核连接、水源及比例尺，再补全水力参数 |
| 纵断面与限值（可选） | 在对应编辑器导入 CSV 或编辑表格；确认管中心高程及边界水头采用同一高程基准 |
| 检查与计算 | 选择适用的 MOC 或 FVM，核对网格、时间步、输出间隔和资源需求，处理阻止项后运行 |
| 结果与比较 | 查看时程、空间结果、风险提示、纵断面和关阀方案区段差异 |
| 保存与交付 | 保存工况 JSON、结果和报告；管网 `.hnr` 归档可用“加载结果归档…”重开；拓扑工具栏可添加文字及导出拓扑 |

纵断面 CSV 表头为 `pipe_id,station_m,centerline_elevation_m`。单管编号固定为 `single`，管网使用实际管段编号；模板位于随包 `data/input/`。

修改工况、剖面或压力限值后需要重新计算。未设置压力限值不代表校核通过；超限区段长度表示统计窗内曾超限位置集合的长度，并非同时超限长度或超限持续时间。

平台用于科研、教学及辅助分析。图纸识别不能替代真实参数测量；本版不求解泵停机、空化、液柱分离或防护设备。出现汽化阈值越界时，单相模型结果不能继续作为有效物理结论。实际工程应用需核验输入数据与模型适用范围。

- **完整客户端升级**：下载本版安装程序按向导操作；也可将完整 ZIP 解压到新文件夹后运行。不要将部分新版文件混合覆盖到旧程序目录。确认新版能打开工况和结果后，再整理旧程序。
- **离线搬运**：可在联网电脑下载完整 ZIP，核对校验值后转移到目标电脑；新设备首次登录仍需联网。

现有软件账户继续沿用。重新安装或解压不等于重新注册；换设备后使用原账户在线登录即可。程序更新前请自行备份工程及结果，尤其是放在旧程序目录中的自建文件。

## 数据、语言与反馈

工况、报告及结果以保存或导出时选择的位置为准，建议集中保存到独立项目目录。默认管网结果位于程序文件夹的 `outputs/network_runs`，可在结果输出页修改。账户授权和登录记忆由当前 Windows 用户保存，复制程序文件夹不会转移本机授权。

- **切换语言**：通过“设置 → 界面语言”选择简体中文或 English，切换前等待计算或导出完成。
- **打开日志**：通过“设置 → 打开日志目录”定位运行日志。
- **更换头像**：点击右上角头像菜单，选择“更换头像…”或“恢复默认头像”。
- **AI 小助手**：在线登录后点击右上角机器人按钮提问；每个账户每天 10 次，回答仅供参考，涉及工程判断请自行复核。
- **反馈问题**：在线登录后使用右上角“反馈”，或提交 [GitHub Issue](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/issues)；制作方的回复可在账户菜单“我的反馈与回复…”中查看。

| 常见现象 | 处理方式 |
| --- | --- |
| 注册仍在等待审核 | 联系制作方确认申请；重复提交不会自动开通 |
| 账户停用、未获批准或授权到期 | 联系制作方核实状态或申请续期 |
| 账户服务连接失败 | 检查网络；首次登录需服务可达，已获有效本机授权时程序会尝试离线登录 |
| 缺少运行库或识图组件 | 重新下载、核对校验值并完整解压，保留整个程序目录 |
| 识图首次启动较慢 | 等待组件加载，查看阶段及状态提示，必要时取消任务 |
| 图片反馈暂不受支持 | 移除图片后提交文字反馈 |
| 小助手提示暂不可用或次数已用完 | 确认已在线登录；每天 10 次，次日恢复，也可直接使用“反馈” |
| 联合设计或误差布点耗时较长 | 在“计算设置”中调整时限，底部进度栏可随时取消；查看证书中的上下界和证明状态 |
| 联系方式申请未生效 | 等待管理员审批；审批前原绑定继续有效 |
| 导出失败或文件被占用 | 关闭占用目标文件的程序，检查目标目录写入权限后重试 |

反馈请附软件版本、Windows 版本、复现步骤、错误提示及可公开的最小示例。公开 Issue 不要附密码、授权缓存、会话信息或未经允许披露的图纸和项目资料；分享日志前请检查其中的个人与项目信息。
