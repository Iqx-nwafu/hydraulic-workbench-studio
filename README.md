# 有压管网瞬态水力仿真平台 · 2.4.9

面向供水与灌溉输配水的水力分析平台，支持单管和分支、环状管网的 MOC/FVM 瞬态计算，将图纸建模、真实纵断面、压力校核、灌水量识别、轮灌规划、监测布设和渠道现场数据分析连接在同一工作台中。

**2.4.9 将无人机影像、农田需水、节点灌水量与轮灌方案连成完整流程，同时支持导入用户自己的灌溉站，联合分析渠道、闸门和测点数据。** 计算和图纸推理在本机完成，账户、更新、AI 小助手与现场数据中转使用阿里云服务。

本仓库提供 **Windows 客户端、科研命令行工具、版本说明和使用文档，不公开软件源代码**。普通用户无需安装 Python、CUDA 或开发环境。

## 2.4.9 新增

1. **灌水量识别**：导入多光谱反射率和温度影像，划定田块并生成方格，估算含水率、用采样点标定、计算作物需水量，再按空间位置分配到灌水节点。一键把结果送到“监测布设与轮灌”。
2. **多目标轮灌**：在灌水时间、压力均匀性、超灌和缺灌之间选择目标，搜索满足硬约束的分组，展示已找到的非支配方案。采用方案后逐组复核水力与水量，再校核误差并布点。
3. **压力地图与轮灌瞬态**：查看各轮灌组的供水路径和压力风险，用 MOC 模拟组间阀门切换，以统一色标回放开阀、交接及关阀过程。
4. **灌溉站渠道监测（试）**：用 Excel 站点表定义渠道、闸门和测点，自动生成三维布置；导入测点文件或采集数据库，分析开度、水位、流量、时间对齐和渠段水量平衡。
5. **现场数据远程同步**：现场工控机定时上传新增读数，平台经审批服务取回并校正时钟偏差。闸门控制默认关闭，开启后可调整开度、闸位或停闸，并查看执行状态。
6. **识图改进闭环**：新增登录图形验证；人工校核后的 PNG/JPG 图纸可自愿提交用于改进模型。用于其他用户登录题目的图纸需要另行授权，图纸识别本身继续在本机运行。
7. **科研接口 API 1.3**：脚本与命令行可调用轮灌、多目标分组、布点、轮灌瞬态、单管/管网瞬态、灌水量识别和渠道水量分析，输出带版本、输入哈希和生效参数的记录。
8. **维护与升级**：增加独立卸载程序，按安装清单删除平台文件，保留计算结果和用户自放文件；改进界面关闭、后台同步、历史补录和小窗口布局。

完整变化见 [2.4.9 更新说明](docs/2.4.9更新说明.txt)。

## 从哪一步开始

| 任务 | 操作路径 |
| --- | --- |
| 分析单管关阀水锤 | 单管模型 → 设置几何与边界 → 检查 → 计算 → 结果浏览 |
| 从图纸建立网络模型 | 网络计算 → 选择图纸并识别 → 人工校核拓扑与水力参数 → 计算 → 结果输出 |
| 校核高点压力与超限区段 | 真实纵断面与压力限值 → 导入/编辑高程 → 重新计算 → 纵断面校核 |
| 用影像制定轮灌制度 | 灌水量识别 → 图像导入 → 土壤水分识别 → 参数标定 → 保存并送往监测布设与轮灌 |
| 比较轮灌方案与布点 | 监测布设与轮灌 → 多目标分组 → 采用方案 → 压力与风险地图 → 校核误差并布点 |
| 监测现场渠道 | 灌溉站渠道监测（试）→ 导入站点 → 连接闸控平台/导入测点数据 → 趋势、对齐与水量平衡 |
| 从研究脚本批量计算 | 科研命令行工具登录 → 调用 api 命令；也可用客户端菜单栏“API”窗口 |

## 主要能力

- **水力模型**：单管、分支与环状管网 MOC/FVM，机械阀门过程、材料与波速、摩阻、自动稳态初始化和守恒检查。
- **建模与结果**：图纸识别与拓扑编辑、批量属性、撤销重做、真实纵断面、压力限值、关阀方案比较、地图/曲线/热图/动画、工况及 `.hnr` 结果归档。
- **图纸与报告**：文字和线标注、编号布局、完整拓扑 PNG/JPG/DWG 导出、CSV 与 HTML 报告。
- **规划与科研**：轮灌、管径联合设计、多目标分组、传感器布设、误差与最优性证书、固定种子蒙特卡洛、无界面计算接口。
- **现场与服务**：用户站点三维、厂家闸控平台接入、测点导入及远程同步、渠段水量平衡、账户与反馈、AI 小助手、分文件更新。

平台有六个工作域，支持中英文界面与显示缩放。不同求解器、优化方法和证书的适用条件不同，可在“帮助 → 模型适用范围”和结果说明中查看。多目标分组展示本次搜索得到的非支配方案；完整 Pareto 前沿或全局最优结论不能由该搜索直接推得。精确优化按所解问题、上界与间隙判断。

## 科研接口 API 1.3

客户端“API”窗口与科研命令行工具调用同一计算接口。轮灌输入为规划 JSON，单管/管网瞬态、影像和渠道分析使用各自工作流的文件。输出保留平台/API 版本、输入哈希与生效参数，方便复现与归档。

```powershell
hydraulic-moc login
hydraulic-moc status
hydraulic-moc api describe --project network.json
hydraulic-moc api evaluate --project network.json --groups groups.jsonl --output results.jsonl
hydraulic-moc api simulate --project network.json --scenario scenario.json --output simulation/
hydraulic-moc api monte-carlo --project network.json --config mc.json --output monte-carlo/ --workers auto
hydraulic-moc api optimize-exact --project network.json --group-size 4 --step-h 4 --time-limit 600 --output exact/
hydraulic-moc api --help
```

API 1.3 还提供 `rotation`、`pipe-transient`、`network-transient`、`soil`、`canal-balance`、`canal-align`。具体输入与选项见 [无界面研究 API 说明](docs/无界面研究API说明.md)。发行版命令行工具需要平台账户，授权有效期内可离线计算。

## 数据与模型说明

图纸识别给出几何、连接和候选类型，水源、尺度、高程、需水、管径、粗糙度和波速仍需人工核对。自愿贡献的图纸用于模型训练与评估，只有另行授权的图纸才可裁成其他用户的登录题目；未提交的工程文件不会因此上传。

土壤含水率估算需结合影像条件和现场采样标定。随包田块与采样点是合成演示数据；KarLy 模型附带的数据集验证记录不代表任意田块的实测精度。现场数据远程同步仅在用户开通后启用，上传读数经审批服务中转并暂存 90 天，账户按授权取回；本地导入和厂家闸控接入可单独使用。
