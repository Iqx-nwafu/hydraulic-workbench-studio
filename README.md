# 有压管网瞬态水力仿真平台 · 2.2.0

用于单管及分支、环状管网的一维瞬态水力计算，支持 MOC/FVM、阀门过程、图纸识别、真实纵断面与压力校核，以及结果报告和关阀方案比较。

本仓库提供 Windows 客户端的下载入口和使用说明。**普通用户无需安装 Python，也无需配置开发环境；下载客户端后，完成注册审批即可使用。** 仓库当前文件和发行附件仅提供用户客户端，不提供审批管理系统。

初次使用：**[下载安装程序](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases/download/v2.2.0/HydraulicWorkbenchStudio-2.2.0-Windows-x64-Setup.exe) → 按向导安装 → 提交注册申请 → 获批后登录。** 喜欢免安装方式，也可选择下方 ZIP。

打开 **[软件下载页面（Releases）](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/releases/latest)**，展开版本下方的 **Assets**，选择完整客户端：

**不要选择 GitHub 自动生成的 `Source code (zip)`、`Source code (tar.gz)`，也不要使用绿色 `Code → Download ZIP` 获取软件。** 这些是仓库文件快照，不是可直接运行的完整客户端。

使用 Windows 10/11 64 位电脑，建议为安装和后续更新预留至少 2 GB 空间。程序已携带运行依赖和本机 CPU 图纸识别组件，无需另装 Python、PyTorch 或 CUDA，也不要求 NVIDIA 显卡。首次注册、首次登录需要联网且账户服务可用。计算所需内存、磁盘和时间随管网规模、网格与输出设置变化，运行前可在“检查”步骤查看资源提示。

## 2. 解压并启动

1. 下载完整客户端 ZIP，在资源管理器中右键选择“全部解压”。解压到当前用户有写入权限、便于长期保存的本地目录。
2. 打开解压后的文件夹，双击 **`HydraulicWorkbenchStudioSecure.exe`**。
3. 请保留完整程序文件夹。不要在压缩包预览窗口内直接运行，也不要单独移动主程序；`auth_distribution.json`、`HydraulicWorkbenchUpdater.exe`、`recognition_runtime` 和其他运行库均需保留。

安装版双击 `HydraulicWorkbenchStudio-2.2.0-Windows-x64-Setup.exe` 后按向导操作，仅为当前 Windows 用户安装，无需管理员密码。完成后从桌面或开始菜单启动。默认程序目录为 `%LOCALAPPDATA%\Programs\HydraulicWorkbenchStudio\client`；示例、说明和默认结果目录均在此目录中。ZIP 版和安装版均使用下述注册、登录及更新流程，已有软件账户可直接登录，无需重新注册。

当前程序未提供 Windows Authenticode 代码签名，Windows 可能显示“未知发布者”。请核对下载来源及校验值；无法确认文件来源或校验不一致时，重新下载或联系制作方，不要关闭安全防护。

可在 ZIP 所在文件夹打开 PowerShell，执行以下命令，将输出的 `Hash` 与 `.zip.sha256` 文件中的值核对：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\HydraulicWorkbenchStudio-2.2.0-Windows-x64.zip'
```

解压目录内的 `SHA256SUMS.txt` 还提供包内文件的校验值。

## 3. 首次注册与登录

### 提交注册申请

1. 启动软件，在登录窗口点击 **“没有账户？提交注册申请”**。
2. 填写以下三个字段。当前注册界面不要求填写手机号或邮箱。

   | 字段 | 规则 |
   | --- | --- |
   | 账户名 | 3～32 个字符；可用中文、字母、数字、下划线、点、短横线或 `@`，不可包含空格 |
   | 密码 | 6～20 个字符；不可使用程序拒绝的常见密码，不可包含完整账户名 |
   | 确认密码 | 与密码完全一致 |

3. 点击 **《用户须知与隐私说明》** 阅读内容，然后勾选 **“我已阅读并同意”**。
4. 点击 **“提交注册申请”**。出现“等待管理员审批”表示申请已提交，尚未取得使用权限。请将申请的账户名通过已有联系渠道告知软件制作方，以便确认审批；不要发送密码。
5. 获批后返回登录界面，在联网状态下输入账户名和密码，点击 **“安全登录”**。账户可使用的期限以实际授权为准。这里使用软件内注册的账户，与你的 GitHub 账户无关。

模型训练授权完全自愿、默认关闭；不勾选不影响注册、审批、登录或计算。2.2.0 不会因勾选而自动上传图纸或自动训练模型。

### 后续登录与离线使用

成功在线登录后，软件会在当前 Windows 用户下保存本机离线授权。之后仍点击“安全登录”；账户服务连接失败时，软件会尝试使用有效的本机离线授权，无需寻找单独的离线登录按钮。

离线使用以本机授权到期时间为准，不是永久授权。换电脑、换 Windows 用户或删除本机授权缓存后，需要重新在线登录。注册、密码修改、账户名变更、发送软件内反馈及授权续期需要联网。可在右上角“设置 → 密码与安全…”办理密码或账户名相关操作。

“记住用户名”和“记住密码”均可自行选择；记忆信息由 Windows DPAPI 加密并绑定当前 Windows 用户。共用电脑不建议记住密码。

## 4. 第一次计算：运行随包示例

建议先使用已配好的示例熟悉 **“1 建模 → 2 检查 → 3 计算 → 4 结果 → 5 报告”**，再录入实际工程数据。以下路径均相对于解压目录或安装目录。

1. 登录后点击 **“模型 → 管网计算”**，再点 **“文件 → 打开当前工况…”**，选择 `configs\longitudinal_network_test.json`。应先进入管网页面，再打开管网工况。
2. 点击 **“模型 → 管网真实纵断面与压力限值…”**。示例管段 `P` 长 100 m，三个管中心高程点为 `0 m / 0 m`、`35 m / 20 m`、`100 m / 0 m`；默认压力水头下限 12 m、上限 36 m。
3. 保留示例设置，点击顶部 **“2 检查”**，查看阻止项及警告。存在阻止项时先修正；本例保留默认 MOC 即可开始。
4. 通过 **“求解 → 运行当前工况”** 或 `F5` 开始计算，等待完成。
5. 进入管网的 **“结果输出”** 页面，在结果工作台选择 **“纵断面校核”**。查看管中心线、最大/最小 HGL 包络及超限区段，点击 35 m 高点查看压力时程。
6. 在结果页查看报告和输出文件。需要调整输出位置时，展开“目录与计算…”，设置自己的结果目录。需要再次编辑的工况通过“文件 → 保存当前工况…”保存为 JSON。

该示例是人工构造的动态工况，供熟悉操作与核对模型行为使用。HGL 是测压管水头，压力水头为 `HGL − 管中心高程`。包络记录计算内部步的极值，可能发生在两个保存帧之间，因此包络极值不一定能在时程保存帧中直接找到。

单管示例可先进入 **“模型 → 单管模型”**，再打开 `configs\longitudinal_single_pipe.json`，按同样的检查、计算和结果流程操作。更完整的 CSV 导入、FVM 对照及关阀方案比较步骤见 [纵断面使用示例](docs/LongitudinalReadme.txt)。

## 5. 用自己的数据开展计算

| 步骤 | 操作要点 |
| --- | --- |
| 建模 | 选择单管或管网；录入几何、材料、波速、摩阻、初始条件、边界及阀门动作。管网按“拓扑参数、工况设置、边界条件、计算设置”逐页核对 |
| 导入图纸（可选） | “文件 → 导入管网图纸（PNG/JPG/JPEG/DXF）…”；识别在本机 CPU 执行，先复核节点、连接、水源及比例尺，再确认导入并补全真实水力参数 |
| 输入纵断面（可选） | 打开对应的“真实纵断面与压力限值”编辑器，导入 CSV 或编辑表格；确认管中心高程及全部边界水头采用同一基准，再应用到工况 |
| 检查与计算 | 选择受当前工况支持的 MOC 或 FVM，检查网格、时间步、输出间隔与资源估计，处理阻止项后运行 |
| 结果与比较 | 查看时程、空间结果、风险提示和纵断面校核；管网批量比较可检查不同关阀方案的“已消除、仍超限、新增”区段 |
| 保存与导出 | 保存工况 JSON，保存/导出结果与报告；管网结果归档 `.hnr` 可通过结果工作台“加载结果归档…”重开 |

纵断面 CSV 表头为 `pipe_id,station_m,centerline_elevation_m`。单管 `pipe_id` 固定为 `single`，管网使用实际管段编号。随包模板分别是 `data\input\longitudinal_single_profile.csv`、`data\input\longitudinal_network_profile.csv`。

修改工况、剖面或压力限值后，已有结果对应的仍是上次运行输入，必须重新计算。未设置压力限值不代表校核通过；超限区段长度表示统计窗内曾超限位置集合的长度，不是同时超限长度或超限持续时间。

软件主要用于科研、教学及辅助分析。图纸识别结果需要人工复核；本版不求解泵停机、空化、液柱分离或防护设备。出现汽化阈值越界时，单相模型结果不能继续作为有效物理结论；实际工程应用前应核验数据与模型适用范围，可从“帮助 → 模型适用范围”查看。

## 6. 升级到新版本

### 软件内更新

1. 保存工况，备份自己保存的工程文件及结果目录。
2. 登录软件，点击右上角 **“设置 → 软件更新…”**。
3. 点击 **“检查更新”**；有可用新版本时选择 **“下载并安装更新”**，按提示完成。
4. 更新期间等待程序完成，不要强制结束更新器或关机。

此入口连接制作方的更新服务。GitHub 发布了新文件，不代表软件内更新服务已同步发布；以更新窗口显示的状态为准。更新服务不可达时，可以使用下方的完整客户端升级方式。

正常软件内更新会保留程序目录中的 `outputs`、`auth_distribution.json`，以及当前 Windows 用户的本地账户授权和设置。其他自建文件请存放在程序目录之外并自行备份，不要依赖更新器保留任意文件。

### 手动升级与离线搬运

如果软件内更新不可用，可从 Releases 下载新版完整客户端 ZIP，**完整解压到新文件夹**后运行。不要把若干新版文件混合覆盖到旧版目录。确认新版能打开工况和结果后，再决定是否清理旧程序。

目标电脑暂时不能下载时，可在另一台联网电脑下载完整客户端 ZIP，通过 U 盘等方式转移并核对校验值。这是完整客户端的离线搬运；新电脑的首次登录仍需联网，已有电脑能否离线登录仍取决于本机有效授权。

2.2.0 客户端没有“导入离线更新包”按钮。名称含 `Offline-Update` 的材料不能直接当作完整客户端解压运行，也不能用它手工覆盖安装目录。

## 7. 工况、结果和账户数据在哪里

| 数据 | 位置及处理方式 |
| --- | --- |
| 工况 JSON、导出报告和结果 | 以保存/导出时选择的路径为准；请集中放在自己的项目目录中备份 |
| 默认管网结果 | 程序目录下 `outputs\network_runs`；可在结果输出页修改 |
| 本机授权、记忆登录及同意记录 | `%LOCALAPPDATA%\HydraulicWorkbench\Client`；由当前 Windows 用户保护，不要公开上传或当作可迁移的账户备份 |
| 界面语言设置 | `%LOCALAPPDATA%\HydraulicWorkbench\ui-preferences.json` |
| 运行日志 | “设置 → 打开日志目录”，默认 `%LOCALAPPDATA%\HydraulicWorkbench\logs` |

复制程序目录到另一台电脑不会同时转移本机授权。重新安装或重新解压不等于需要重新注册：已有账户可在新设备上重新在线登录。需要续期时联系软件制作方，无需反复创建账户。

安装版可在 Windows“设置 → 应用”中卸载。卸载保留计算输出、用户添加的文件及本机授权、设置；请在确认备份后自行整理剩余文件。不要删除安装目录的 `.installer` 文件夹。软件内更新后的版本以程序界面为准，Windows 应用列表可能仍显示最初安装包的版本。

界面语言可在 **“设置 → 界面语言”** 中切换为“中文（简体）”或“English”；切换前等待正在运行的计算或导出任务完成。

## 8. 常见问题与反馈

| 提示/现象 | 处理方式 |
| --- | --- |
| 等待管理员审批 | 申请已提交，等待制作方审批；反复提交不会自动开通 |
| 申请未获批准、账户停用或使用期限到期 | 联系制作方核实账户状态或申请延长使用期限 |
| 管理端离线、无法连接审批中心 | 检查网络，联系制作方确认服务是否在线；首次登录需要服务可达，已取得有效本机离线授权的账户可由程序尝试离线登录 |
| 登录尝试过多、临时锁定 | 按提示等待后再试，并确认账户名及密码 |
| 缺少配置、运行库或识图组件 | 重新下载并完整解压客户端，核对校验值，保留整个目录 |
| 识图启动较慢 | 独立进程需要解包和加载模型；查看阶段、耗时及状态提示，可取消任务 |
| 导出失败、文件被占用 | 关闭正在打开该结果的其他程序，检查目标目录写入权限后重试 |

登录后可用右上角 **“反馈”** 按钮提交问题（需要在线登录），也可通过 **[GitHub Issues](https://github.com/Iqx-nwafu/hydraulic-workbench-studio/issues)** 报告软件问题。

反馈建议包含：软件版本、Windows 版本、操作步骤、完整错误提示，以及可公开的最小示例。日志可从“设置 → 打开日志目录”取得。**公开 Issue 不要附密码、授权缓存、会话信息或未经允许披露的工程图纸和项目资料；提供日志前先检查其中的私人路径、账户及项目信息。**
